# Ibadi Sources

This file records the historical sources considered for the research corpus.

## Initial Source

### Abu Zakariya al-Warjalani

- Author: Abu Zakariya Yahya ibn Abi Bakr al-Warjalani
- Work: *Siyar al-A'imma wa-Akhbarihim*
- Tradition: Ibadi
- Role in the project: Initial historical source for extracting evidence related to scholars, places, movements, and intellectual connections.
- Status: To be documented and verified against the specific edition or digital copy consulted.

## Source Documentation Principles

Each source will be documented with:

- Author
- Title
- Edition or digital version consulted
- Bibliographic reference
- Relevant page or location
- Relationship between extracted data and the source evidence
